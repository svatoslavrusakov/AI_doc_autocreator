# local-llm-document-agent

Локальный помощник для подготовки актов выполненных работ по командам в чате.
Учебный проект технического портфолио.

## Архитектура
Streamlit (`frontend.py`) → отдельный LLMAgent для каждой браузерной сессии
(`main.py`) → LangGraph ReAct с памятью InMemorySaver → инструмент
update_act_pdf → ReportLab (`pdf_generator.py`) → output/.
`models.py` содержит dataclass-модели заказчика, банка и работ;
`config.py` задаёт пути и регистрирует включённый DejaVu Sans.
Технологии: Python, LangChain, LangGraph, Streamlit, ReportLab, KoboldCpp, Qwen.

## Установка и запуск
Python 3.10+ (проверка выполняется в существующем локальном окружении).

```powershell
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt
streamlit run frontend.py
```

Для Linux: `source .venv/bin/activate`.
Консольный интерфейс: `python main.py [путь_к_реквизитам]`, завершение: `exit`.

## KoboldCpp
Отдельно установите KoboldCpp, загрузите совместимую GGUF-модель Qwen,
выберите соответствующий модели chat template и запустите локальный сервер
на порту 5001. Endpoint приложения: http://localhost:5001/v1.
Нужна поддержка OpenAI tool calling сервером и моделью: наличие chat endpoint
само по себе не гарантирует работу агента. Небольшие модели могут ошибаться.
Настройки задаются переменными окружения LLM_BASE_URL, LLM_MODEL,
LLM_API_KEY (по умолчанию not-needed). Файлы .env автоматически не читаются.
Модель в репозиторий не входит.

Приоритет реквизитов: аргумент консоли → REQUISITES_FILE → req.txt → examples/requisites.txt. Для собственных данных
задайте REQUISITES_FILE — путь к приватному UTF-8 файлу вне репозитория.

## Демонстрация
Все демонстрационные реквизиты вымышлены, номера нулевые.
Пример: «Создай акт для демонстрационного заказчика в городе Примерск
за сегодня: разработка макета — 5000 рублей».
Пример результата: examples/demo.pdf. Каждый вызов создаёт отдельную версию;
явный filepath в Python позволяет перезаписать выбранный файл.

## Ограничения
Это прототип, не юридическая или бухгалтерская система. Подпись исполнителя заполняется вручную. Нет
НДС, автоматической нумерации документов и проверки реквизитов. Цены — целые рубли.
Память диалога и последний успешно сохранённый акт хранятся в процессе
и теряются при перезапуске. Модель получает сохранённый акт при следующем запросе. PDF в output общие для локального
интерфейса: приложение рассчитано на доверенное однопользовательское окружение.
Не публикуйте сервис в интернете. Проверяйте содержание перед использованием.
Шрифт DejaVu распространяется с лицензией в assets/fonts/LICENSE_DEJAVU.
Интеграция с работающей LLM в рамках подготовки не проверялась.

Проверки: `python -m compileall config.py models.py main.py frontend.py pdf_generator.py`,
`python -m pip check`. Реальные файлы output и локальное окружение исключены из Git;
не публикуйте их или историю с конфиденциальными данными.

Регрессионные проверки без LLM: `python -m unittest -v test_project`.
